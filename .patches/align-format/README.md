# Patch: align-format

Single foundational patch over `../../objects/`. Two layers:

1. **Format normalization** — make every MD conform to the strict layout the parser expects (canonical table headers, divider, identity field order, sentinels for empty cells, ...).
2. **Opinionated content adaptations** — additional shaping the runtime expects: split combined transition rows, canonicalise action names, fold embedded sub-objects out into their own files, surface implicit terminal states, expand sub-field tables into the main attribute list with dot notation. Each adaptation is documented in `CHANGELOG.md` with what / why / which files.

After this patch is applied the source MDs together with the patch describe the canon as the runtime parser, validator, and MCP servers expect — one section, one canonical-shape table, one file per object, every domain-bearing line either typed or captured as a `note`.

Generated by `.canon/scripts/align.js`. See `CHANGELOG.md` next to this file for the full per-transform rationale.
