# Canon Session Start

We are going to author a new Object Canon document for the SoftwareOne Marketplace canon knowledge base.

All paths below are relative to the root of the `mpt-marketplace-canon` repository.

Before we begin, read the following files from the filesystem in this order:

1. `preamble/PLATFORM_CANON_PREAMBLE.md` — platform-wide invariants, Actor model, API conventions, namespace model, and design philosophy. This is authoritative. Do not contradict it.

2. `templates/CANON_AUTHORING_SESSION_PROMPT.md` — your operating instructions for this session. This defines how we work together, section-by-section guidance, JSON sample handling, language standards, and the open questions protocol.

3. `templates/CANON_OBJECT_TEMPLATE.md` — the required structure for every canon document. We will fill this in for the object we are canonising.

4. `questions/CANON_OPEN_QUESTIONS.md` — the live open questions tracker. Familiarise yourself with existing question IDs so you do not reuse them.

5. `objects/` — scan the existing canon files so you know what has already been canonised and can cross-reference correctly.

All work must be written directly to the filesystem. Do not store drafts as conversational context. New canon files belong in `objects/`. Batch changes and write to files only when instructed — do not write after every small change. Always read a file immediately before editing it.

Once you have read all of the above, confirm you are ready and ask me for the object details.
